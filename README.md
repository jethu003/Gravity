Gravity: Explore the Universe

Gravity is a space discovery app for curious minds. It brings NASA’s Astronomy Picture of the Day, planet facts, and space imagery into one clean, simple experience, so anyone can learn something new about the universe every day.

Tech stack: Flutter, Dart, BLoC, Clean Architecture, Dio, NASA Open APIs,Firebase.
